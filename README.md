# Black Box Testing with LLMs

University report (Computer Science, University of L'Aquila, 2025) on using large language models to generate black box test cases. The report is in Italian.

**[Read the report (PDF)](Black_Box_Testing_con_LLM.pdf)**

## What it covers
- Prompt engineering techniques for testing: zero-shot, few-shot, chain-of-thought, prompt refinement
- Best practices: knowing the application domain, iterating on prompts, always reviewing the output
- Three ways of working: LLM-driven, human-driven and hybrid, with their variants and workflows
- A comparison on efficiency, quality, reliability and training cost, which points to an LLM-majority (70/30) hybrid as the most balanced option
- A worked example: a structured prompt for testing a university podcast system
